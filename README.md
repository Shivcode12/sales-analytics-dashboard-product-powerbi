# sales-analytics-dashboard-product-powerbi

_Sales of Product – Power BI Dashboard_
This repository contains a Power BI Project (.pbip) that analyzes product 
sales performance using interactive visuals and dynamic insights. 
The dashboard helps identify sales trends, top-performing products, 
revenue patterns, and actionable KPIs to support better decision-making.

_Features_
*Total Sales Overview – High-level revenue and quantity metrics
*Product-Wise Sales Analysis – Identify top and bottom performers
*Region/Category Breakdown – Understand performance across segments
*Trend Analysis – Monthly/Yearly sales growth visuals
*Interactive Filters – Slicers for category, product, region, and date
*Clean & Professional UI – Built using Power BI best practices

_Tools & Technologies_
*Power BI Desktop
*DAX (Data Analysis Expressions)
*Power Query
*Data Modelling
*Excel / CSV (Data Source)

_Future Enhancements_
